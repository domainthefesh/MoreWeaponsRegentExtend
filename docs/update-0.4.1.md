## 逐项改动

1. **重压共享显示与施加阈值。** 同一玩家的所有重锤共享本场战斗达到过的最高 `10＋累计铸造` 阈值，更新已存在重锤的卡面，新生成的重锤也直接继承。移除最高铸造重锤或替换全部旧锤后仍保留该阈值；不同玩家和新战斗独立。攻击伤害继续按各张卡自身铸造计算，临时重放副本不提高共享值。已有敌方重压保持施加时的快照，再施加时才提高阈值，层数继续叠加。
2. **邪皇圣弓卡图纠正。** 依据作者已验收的悬浮 C 素材重绘 B 卡图，恢复正常连续 C 弧、同侧弓梢和连接两端的直弦，保留银色、金/紫两侧纹路。已验收悬浮素材保持。
3. **皇室猎枪外观重新设计。** 卡图 B、悬浮/使用 C、状态图标 D 均改为金蓝杠杆式步枪，保留固定枪托、机匣、上下平行管及独立扳机/杠杆环，外观取法马林杠杆式轮廓；效果不变。远程兵器库同步同款猎枪，并修正银弓弦梢连接。仅参考公开外观类别，不复制游戏贴图。
4. **全武器恢复原版斜向椭圆。** 直接提取原版 `scenes/vfx/sovereign_blade.tscn` 的五点 Curve2D，保留原 Path 位置 `(87.7143,79.5227)`、缩放 `(2.14732,0.998972)`、60 px/s 曲线行进速度和 0.25～0.78 的人物后方遮挡区间。运动进度按帧累计，悬停暂停；人物移动/缩放时跟随。Visual 统一放大 **1.35 倍**，Sprite、粒子和命中框共同放大，轨道本身不放大。地图显隐、战后清理与攻击复位保留。
5. **厚重兵器库重锤纠正。** 锤头与柄恢复正常 T 形、垂直轴线及中央套箍连接，其余四件武器与布局保留。
6. **固定美术审批流程与后续方向。** 六项美术均由制作代理自查、主代理实际逐张打开复审后采用；错误初稿退回，记录见 [美术复审](art-review-0.4.1.md)。后续武器扩充与完整独立养成界面已经写入 [路线](roadmap.md)，本轮未实现养成系统。

## 游戏复验步骤

1. 同一战斗生成两张不同铸造量的重锤：卡面共享阈值相同，伤害仍各自计算。提高任意一张的铸造量，所有重锤阈值同步；移除旧锤再生成时继承，下一战斗回到新战斗自己的值。
2. 使用重锤施加重压：实际能力阈值等于卡面共享阈值；单段最终伤害低于阈值为 0，等于阈值正常结算。继续铸造后，已有重压在再次施加时更新。
3. 生成数种武器：沿原版斜椭圆在人物前后环绕，尺寸较上一版扩大；既有右向与翻转方向正确。悬停、连续重放、攻击复位无异常；地图隐藏和战后清理正常。
4. 检查邪皇圣弓卡图、猎枪 B/C/D、厚重与远程兵器库：弓弦连接正常、猎枪杠杆轮廓清晰、重锤 T 形正常，卡框及小图标显示可辨识。
5. 多人使用时复验各玩家重压共享值互相独立；本轮没有完整实机联机验收。
