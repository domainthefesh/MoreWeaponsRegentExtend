# 0.5.2 卡框日志与原版武器联动修复

日期：2026-10-05。作者确认上一轮各武器直接效果没有问题，本轮处理重复卡框日志和 Parry 对非攻击武器不生效，并审查当前游戏版本全部君王之剑专属联动。改动仅在本项目内；没有新增第三方库。

## 日志结论

所贴 75 行日志中有 73 行完整的 RitsuLib 资源警告，另有一行同类截断提示。完整警告分别来自趁手兵器 5 次、银河轨迹炮 20 次、充能 48 次，都指向不存在的 `card_frame_skill.png` 或 `card_frame_attack.png`。共同基类还配置了同样不存在的能力卡框。

这类提示报告的是 **自定义卡框缺失**，并非武器轨道或施放特效失效。日志明确说明已经回退到原版资源，因此这些提示不会阻止对应卡牌加载。重复资源查询和日志输出有额外开销；没有实机帧时间采样，不能由这段日志推断具体 FPS 损失。

`MoreWeaponsCardBase` 和单独的 `HandyWeapon` 现在只指定卡图路径，让 RitsuLib 正常使用原版卡框；移除了无效的自定义卡框请求。没有屏蔽日志，也没有修改已验收轨迹、美术或特效。

## 逐项改动

| 改动 | 结果 |
| --- | --- |
| 君王之翼、皇室猎枪 | 补齐 Parry 计算变量、卡面格挡预览和每次实际出牌的格挡结算；技能牌和能力牌同样适用 |
| 君王之盾 | 保留自身格挡，攻击后额外获得 Parry 格挡；不会用本次新获得的 Parry 格挡放大本次盾击 |
| 君王之盾、水晶小刀、子弹 | 补齐追踪之刃的群攻目标与群攻施放分支，支持空 `cardPlay.Target` |
| 水晶小刀、子弹 | 补齐 Parry；子弹同时接入征服者、剑术大师及召唤之刃 |
| 武器身份判断 | 将原版联动资格与铸造生成判定分开；已有子弹仍不阻止皇室猎枪继续生成新子弹 |
| Parry 预览与中文卡面 | 预览补上猎枪与两张附属武器；18 张武器在拥有 Parry 时显示当前额外格挡，无 Parry 时隐藏该行；趁手兵器与充能不获得此效果 |
| 旧武器首次铸造 | 长弓、晶刃、盾、斧原先手工加值后又经过全局钩子，首铸计算两遍；统一只由全局钩子结算一次 |
| 子弹首次铸造 | 同样去掉生成时的额外手工加值；连续铸造仍各生成一张新子弹，已有子弹正常再受铸造 |

Parry 沿用原版 `CreatureCmd.GainBlock`，每次实际出牌结算一次，并由原版统一处理敏捷、脆弱等修正。群攻不会按敌人数重复获得格挡；原版重复出牌则每次正常获得格挡。

## 原版联动审查

当前本地游戏程序集的君王之剑专属效果集中在 Parry、召唤之刃、剑术大师和征服者，追踪之刃由各武器读取对应能力。16 件主武器和水晶小刀／子弹均接入这些联动；炮和圣棍保留已经约定的特殊追踪规则。

原版铸造卡 BeatIntoShape、BigBang、Bulwark、Conqueror、RefineBlade、SeekingEdge、SpoilsOfBattle、SummonForth、TheSmith、WroughtInWar，以及 Furnace／HammerTime 和 FencingManual 遗物，经同一 `ForgeCmd.Forge` 入口接入。其余精确 `SovereignBlade` 引用为提示、视觉、成就或模型注册，不存在额外遗漏的卡牌专属效果。

## 游戏复验

1. 启用新版三文件后打出趁手兵器，并生成、查看炮与充能，确认不再反复出现本轮自定义卡框缺失提示，卡面仍正常。
2. 打出 Parry，再分别使用君王之翼、皇室猎枪及任意攻击武器：基础 Parry 各获得 10 格挡，升级版各获得 14；君王之盾还保留自身格挡。叠加敏捷或脆弱时，以原版修正值为准。
3. 使用追踪之刃，确认盾、小刀、子弹攻击全部敌人；单次群攻的 Parry 格挡只结算一次。剑术大师重复出牌每次分别获得格挡，炮仍按原设计额外出牌。
4. 以召唤之刃取回弃牌／抽牌／消耗堆的武器；征服者对目标上的武器攻击增伤，剑术大师对已有与新生成武器均生效。
5. 首次铸造 3：长弓伤害 11、晶刃伤害 6、盾基础格挡 8、斧伤害 11。激活枪后铸造 3，新子弹伤害 6；再铸造 3，旧弹伤害 9、新弹伤害 6。
