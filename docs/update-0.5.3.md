# 0.5.3：完整英文、新发布图与卡框试作

日期：2026-10-05。作者已验收 0.5.2 的 Parry 正确显示和获得格挡，各武器联动正确。本轮沿用该玩法基线，补齐发布所需的文本与素材。

## 逐项改动

1. **完整英文四表。** 新增 `MoreWeaponsRegentExtend/localization/eng/`：20 张卡的 40 项名称／描述、8 种能力的 19 项名称／静态及实时描述、8 个关键词的 16 项、兵器库的 78 项事件及选项，共 153 项。键集合、变量名称与次数、富文本标签顺序与中文一致。保留 Parry 显隐、三种架势、冷热启动、多炮编号、充能槽位、实时能力与分页文本；攻击次数使用原版 `plural` 格式，单次攻击不显示“1 times”。术语来自实际游戏英文表，名称在卡面、选项和完成页统一。详见 [翻译说明](english-localization-0.5.3.md)。
2. **新工坊发布图。** 储君与五件代表武器，干净的深蓝金色构图，双语标题。初稿的圣棍结构错误退回修正，主代理逐张打开修正稿和缩小后的上传版检查通过。交付 1254×1254 高清原稿与 768×768 上传图；上传图 873,977 字节，小于 1 MB。另准备中英双语工坊介绍及全面更新说明。详见 [发布素材与审批记录](release-0.5.3/README.md)。
3. **独特卡框试作。** 攻击、技能、能力三类深蓝金色框，沿用实际 NCard 布局与三类图窗轮廓；交付 7 个 SVG、同尺寸 PNG、原生保色材质及完整卡面合成预览。候选尚未启用，正式资源包继续使用原版卡框。RitsuLib 支持实际接入；采用后仍需卡名、说明、升级、附魔等实机状态检查。详见 [预览及技术说明](card-frame-trial/README.md)。
4. **进度与发布指引。** 记录本轮作者验收，更新进度、待办、路线和 README。依据截图统计补充更新旧条目与另发新条目的利弊，准备新的封面与文案路径。未代为上传或发宣传信息。

未改变卡牌／能力／存档 ID、战斗数值、武器池和既有玩法。正式 DLL 的 SHA256 与已验收 0.5.2 完全相同。本轮只新增英文资源、发布及卡框候选文件，manifest 版本升为 0.5.3；未引入第三方库。

## 游戏复验建议

1. 启用本版三文件，切换英文，新开储君局。涅奥结束后查看兵器库母页、分类页、每把武器及返回／翻页，确认英文不溢出、页码正确。
2. 查看三种圣棍架势、炮及三槽 Charge、多炮编号、基础和铸造后的圣典、重压／眩晕／适应实时提示；不存在 `{Variable}` 原样显示。
3. 打出 Parry 后查看翼、枪、盾、攻击武器和附属牌，格挡行按状态显示并结算；Parry 失效后隐藏额外行。
4. 查看圣弓、轨迹炮等较长英文名称与描述，检查升级卡、卡库、悬停与手牌的字体自动缩放。
5. 切回中文，原效果与原美术应保持已验收表现。卡框候选只在预览文件显示，游戏仍为原版框。

工坊更新仍建议保留原条目，配合新封面与双语文案完整重新展示。具体说明见 [发布指南](workshop-publishing.md)。
