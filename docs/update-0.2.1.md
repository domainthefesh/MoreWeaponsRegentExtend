# 0.2.1 验收修复

本次按玩家的四项验收反馈调整。沿用 STS2-RitsuLib 0.6.2 和现有 Godot 4.5.1 资源，未引入新依赖，所有源码、资源、构建与验证输出均位于仓库目录。

## 改动点

1. **新增武器环绕。** 海王三叉戟、太刀、君王之翼、君王短匕具有持续环绕储君的独立场景（scenes/orbit）。攻击武器飞向敌人后回到环绕位置；君王之翼保留环绕并播放展开翅膀的使用特效。牌进入有效战斗牌堆时挂载，消耗、离开战斗、变形或战斗节点销毁时清理。趁手兵器为铸造技能，保留现有开箱使用特效。
2. **旧牌攻击/使用特效。** 为君王重锤、天启长弓、君王晶刃、君王之盾、君王长矛、君王重斧、君王镰刀、君王新枪、水晶小刀和子弹添加独立瞬时场景（scenes/cast）。攻击特效在伤害前播放，盾与枪的使用特效在储君处播放。君王新枪另加专属环绕场景，移除原版铸造特效对不存在的 Damage 变量的访问，避免先挂一把原版剑再抛异常。
3. **卡牌停留画面中央。** 追踪之刃将目标类型改为 AllEnemies 后，原版打牌流程会把 CardPlay.Target 设为空。旧斧在伤害结束后仍向该目标施加流血，触发空目标异常，使结算无法继续到移出出牌堆。长弓的随机负面效果及镰刀的灾厄有同样路径。现在统一从 AttackCommand.Results 读取实际受击者、去重并过滤死亡单位，为每个存活受击者施加附加效果。已审查其他旧牌，未发现同类群体攻击后访问单体目标的问题。
4. **武器动画复位与复制牌。** 新旧环绕控制器共用 WeaponMotion，保存初始局部位置和旋转；多段攻击或重放打断动画时，先复位再飞出，返回时使用局部坐标。临时重放副本共享原牌攻击动画，但不负责创建或移除原牌特效；独立复制牌通过自己的卡牌实例挂载特效，避免复制了旧缓存却未创建武器。
5. **居高临下提示。** 原版从卡牌生成的能力提示使用 GetDumbHoverTip，不填入任意自定义 DynamicVars，故原先的 DamageDecrease/DamageIncrease 占位符原样显示。50% 是本能力固定规则，描述直接使用 50%，与现有减伤和增伤倍率保持一致。

## 验证

- 使用本机实际 sts2.dll、缓存 RitsuLib 与 Godot SDK 编译通过：0 错误、0 警告。
- 原生 Godot 分别验证 5 个新增环绕场景（含旧牌君王新枪）和 10 个旧牌瞬时场景的实例化与贴图。
- 真实 Godot C# 直接链接 WeaponMotion.cs，验证正常攻击返回、在敌方位置连续打断重放、父节点移动旋转、主动 Reset 和释放节点中断，共 5 组，全部通过。
- 最终资源包 27 项检查全部通过，覆盖 5 张卡图、15 个瞬时场景、5 个新环绕场景、能力图标和能力中文描述。
- 当前未启动游戏进行本轮实机复验；上述 Godot 验证与实际 DLL 调用链审查不代替游戏验收。

## 游戏复验步骤

1. 使用本轮 DLL、JSON 与 PCK 三件套启动游戏。分别铸造四件新增武器，确认绕储君转动、丢弃后仍在、消耗后消失；三叉戟从消耗堆回手时恢复环绕。
2. 打出太刀、短匕、三叉戟，确认飞向目标并回位；连续多段攻击/自动重放时也回位。使用君王之翼，确认展开特效与持续环绕。
3. 分别使用旧武器与衍生牌，确认命中特效；盾与枪应在角色处表现。
4. 面对两名及以上敌人先打出追踪之刃，再打出斧、已铸造的镰刀、长弓。确认群体伤害后附加效果作用于各存活受击者，牌结算后离开画面中央，后续出牌正常。另测杀死其中一名敌人的情况。
5. 复制并重放一件武器，确认临时副本结算后原牌环绕仍在；独立复制出的牌有自己的武器，战斗结束后无残留。
6. 悬停君王之翼及角色身上的居高临下，确认显示减伤 50%、增伤 50%，不再出现花括号变量名。

本地三件套输出目录：.build/package/MoreWeaponsRegentExtend/。详细构建方法继续参见 update-0.2.0.md。
