# 0.6.6 验收后的界面与文本小修

日期：2026-10-11。

作者已在游戏中确认0.6.5的新增支线加载、完成与领取正确，沉重／轻盈互斥正确，武器升级补全正确。本轮修正图谱显示并复审任务、卡牌及相关提示文本，保留已验收的数值、任务条件与战斗机制。

## 改动

1. **详情展开后的节点显示。** 上一版根据节点的固定设计坐标，将右侧两枚节点统一设为不可见；图谱拖动、缩放后仍沿用该判断。本轮删除该隐藏规则，详情面板通过正常绘制与输入层级覆盖其实际占据的区域。移到详情外的轻盈、断水节点继续显示且可点击。
2. **任务颜色。** 复用原版槽框，主线为金色，沉重灰色、轻盈白色、断水蓝色、理气粉色、怨魂紫色、淬火红色、淬玉青色。聚焦、可领取及已领取状态仍保留任务颜色；已领取的绿色勾记继续表示完成。
3. **任务详情标黄。** 任务要求与奖励改用富文本，机制关键词标黄，普通正文采用原版浅色及黑边字体。节点名、进度、按钮维持纯文本。精简重复解释，并保留首次触发、费用下限、互斥范围与持续方式。
4. **英文详情按钮。** 互斥状态的长按钮文本曾撑宽整个详情栏，挤出关闭按钮。本轮固定文字裁切并显示省略号，完整原因保留在状态正文和按钮提示中。
5. **卡牌文本复审。** 将全部20张模组卡牌、关键词与能力提示逐项对照代码，纠正猎枪、圣弓、之翼和碎裂等旧说明的歧义，补齐机制关键词颜色。两种语言在各自文件中对应维护，不改卡名、动态变量或效果数值。具体条目及作者手修位置见[text-review-0.6.6.md](text-review-0.6.6.md)。

## 人工复验

1. 打开任意任务详情，拖动或缩小图谱，把轻盈、断水移出详情范围；两枚节点应显示且能切换详情。重置后，详情只遮挡与其重叠的区域。
2. 查看九节点的颜色、已领取勾记及任务正文关键词；切换英文，检查互斥任务的长状态按钮与关闭按钮。
3. 检查重锤门槛、猎枪王之枪、圣弓命锁顺序、之翼基础比例，以及晶刃、架势、轨迹炮的说明。招架和淬炼后的动态数值仍应正常显示。

开发与打包限于本项目目录，未写入游戏安装目录，也未上传工坊。
