# 0.6.0：本局兵器淬炼

制作日期：2026-10-06。基于 STS2-RitsuLib 0.6.2，未新增第三方库，修改与测试产物均留在本项目目录。

## 本轮规则

本次实现的是**本局阶段强化**。击败第一幕、第二幕首领后，在独立任务页面分别领取一阶、二阶淬炼；二阶必须先领取一阶。查看任务不会自动领取。

- 入口位于原生顶栏地图／牌组区域，图标为兵器淬炼。
- 页面包含17件兵器目录、两个连线任务节点、奖励说明与领取按钮。支持中文、英文、滚动、键盘／手柄返回与 Escape 关闭。
- 指定兵器及“随心所欲”仅给本局实际选定的兵器领取。其他兵器可查看。
- “百武皆通”允许每件兵器分别领取，两幕首领条件通用，领取状态各自独立。
- 战斗中可以查看；战斗结束后领取，随后保存本局数据。
- 保存退出可恢复首领进度、各兵器已领奖状态和原版剑累计成长。开始新局全部清零。
- “首次打出”按每场战斗、每张实体卡一次；真实复制的新卡独立，额外重放不重复获得首次收益。

## 新状态与其他改动

1. **命锁**持续本场战斗，重复施加不叠加固定加成；只放大正向施加的负面层数，不放大正面效果、减层或自身重复施加。
2. **撕裂**每次发动攻击损失10%最大生命值并减少1层。多段攻击或多目标的同一次攻击只触发一次；两层对应两次攻击。
3. **海啸**首次施加立即把现有格挡减半，后续格挡获取也减半。重复施加不再次削减现有格挡，固定加成不叠加。
4. 三项新状态各有独立图标。中文、英文卡面、能力、事件、任务与顶栏提示同步更新。
5. 开局兵器库新增“选最熟悉的”，走原版君王之剑铸造路径；主页面保持最多四项，原四组分类与分页保留。
6. 皇家指虎基础适应上限从4降至2，每层仍按加法提供20%减伤和20%增伤。
7. 重压卡面及能力说明精简，保留低于门槛归零、施加时记录和叠层规则。
8. 保留0.5.4的征服者统一铸造入口及单件武器提示修复，没有修改已验收的轨道和武器美术。

## 实现与验证

核心使用 RitsuLib 的玩家本局存档、原生战斗胜利生命周期和 Sidecar 可靠消息。联机请求只传武器与节点，玩家身份从传输发送者取得；重复或越级领取、战斗中领取均拒绝。

界面使用原生 Godot `ICapstoneScreen` 与 Ritsu 顶栏注册。输入阻挡、打开／关闭和战斗暂停由原生屏幕容器管理，关闭释放热键阻挡，退出场景解除事件订阅。

## 游戏内验收步骤

1. 储君新开局，涅奥后选择具体兵器；确认主页面四项、分组分页可用。“选最熟悉的”应生成原版君王之剑。
2. 打开顶栏兵器淬炼：未击败首领时无法领取，非选定兵器可以查看但不能领取。关闭后地图与出牌正常。
3. 击败第一幕首领，领取一阶；下一场核对表中该兵器奖励，二阶仍未完成。击败第二幕首领后领取二阶。
4. 保存退出再继续，确认状态与强化仍在。另开新局确认重置。
5. “百武皆通”分别领取多件兵器，确认只影响各自奖励。测试原版剑多个斩杀、下一场生成新剑的累计＋10。
6. 用复制与剑术大师检查盾、太刀、圣棍、圣典的首次收益；充能强化后新炮应只生成一张绑定充能。
7. 检查新状态图标、动态卡面和中英文提示；多段敌方攻击只消耗一层撕裂。
8. 如使用联机，再验证不同玩家的武器、领取、退出重进与同步；自动消息校验不算双客户端验收。

最终安装包在 `.build/MoreWeaponsRegentExtend-0.6.0.zip`。仅包含本模组DLL、PCK与清单，前置RitsuLib继续使用工坊订阅；本轮未上传Steam。
