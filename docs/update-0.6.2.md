# 0.6.2：三叉戟修正与任务图谱重新设计

日期：2026-10-07。作者确认0.6.1所有卡牌改动已实现。本轮按最终更正调整三叉戟一阶，重新制作三份可扩展图谱参考；海克斯兼容按作者后续决定延期。

## 逐项改动

1. **海王三叉戟一阶：每场战斗每张实体卡首次打出获得10层雷霆。** 作者澄清原文“引雷10”为笔误，实际为“首次打出获得10层雷霆”。每次打出的基础引雷1保持；真实复制独立计算，额外重放不重复获得雷霆，铸造不放大雷霆层数。卡面、任务与DLL后备说明同步中英文。
2. **重新设计三份任务图谱。** A皇家任务图谱、B兵器册地图、C宽阔星图，均使用原版简中字体，加黑色描边和彩色填充；局部引用实际游戏PCK的青绿横栏与复选框边框，继续使用已验收武器素材。
3. **清理画面信息。** 主线节点只写“淬炼一／淬炼二”；任务要求、奖励与领取点击后才显示，详情默认关闭。游戏画面删除持续本局、领取说明、可领取／可查看、设计预览与重置演示等多余文字。重置和模式切换只保留在测试API，不能作为生产控件接入。
4. **预留支线空间。** 三版采用可平移、缩放和归位的图谱；不再用两节点或大武器陈列塞满画面。加入作者提出的“击败5个精英”作为空间验证示例，短名“精英狩猎”；没有编造奖励，不写入正式游戏任务，也不能领取。
5. **海克斯兼容延期。** 本机没有安装海克斯大乱斗，作者明确允许以后处理。本轮只保存[只读调查](../.build/hex-compat-0.6.2/README.md)，未修改开局切换流程，未实现剑收益兼容。历史源码提示双方均处理Neow结束／Proceed流程，多项符文硬筛选SovereignBlade；需安装明确版本后核对真实DLL并做串行入口及逐项收益兼容，不能把当前版本称作兼容通过。

主代理逐张查看1600×900默认图谱和1280×720详情截图，并复审小尺寸默认图谱。初稿发现A/C奖励被flex压缩、标签描边绘制次序不正确、拖动产生浏览器文字选区，已退回修正并重新截图。最终奖励有独立可滚动空间，按钮可见；菜单重置回到起点，原版黑描边字可读。

- 正式编译：**0警告、0错误**；PCK297文件、78项导入资源。日志`.build/acceptance-0.6.2-build.log`。隔离Godot的证书存储提示为既有宿主消息，打包正常完成。
- 实际DLL回归：**308项通过**，编译零警告／零错误、进程正常退出0。首次10、重复10、真实复制累计20、剑术大师三次打出总雷霆10／引雷3；一阶单独领取＋铸造7、未领取无雷霆；中英卡面、任务与后备文本数值10。其余已验收平衡效果一起回归。证据[专项记录](../.build/trident-0.6.2-validation/README.md)。夹具使用固定活跃门禁，不能替代最后击杀或完整游戏客户端验收。
- 三份页面：**615项浏览器检查通过**，覆盖17兵器34奖励、详情开关、两阶顺序、固定／随机资格、示例支线不能领奖、原版字体与黑描边、图片加载、平移缩放、关闭重开、1280界限以及两分辨率下正文实际可见和按钮边界。日志`.build/ui-design-0.6.2-qa.log`。
- 汇总入口：**31项检查通过**，实际HTTP字体／素材加载、三个iframe切换、点击节点展开、领取及返回，零脚本和请求错误。日志`.build/ui-design-0.6.2-index-qa.log`。

## 游戏内复验

选择三叉戟并领取一阶：第一次打出应获得雷霆10与基础引雷1；再次打出同张只增加引雷，真实复制首次另获雷霆10，剑术大师的完整三次出牌只触发一次首次奖励。未领取一阶时不获得雷霆。二阶海啸保持先施加、后伤害。
