## 封面制作与审批

使用内置 imagegen，参考已验收的兵器库母图、轻巧、远程和特殊插画。构图为储君居中，五件代表武器沿斜向椭圆分布：蓝色君王晶刃、金端红身定海圣棍、银色金紫反曲圣弓、金蓝杠杆式皇室猎枪、白金光之圣典。背景为简洁的深蓝金色兵器库；标题为“百般武艺 / SOVEREIGN ARSENAL / 储君扩展 · REGENT EXPANSION”。

初稿将定海圣棍误画成红柄三叉戟，主代理视检后退回，只修正该件武器。修正稿检查通过：圣棍两端为金色圆柱端帽，棍身红色且连续；圣弓两弓臂与单根弓弦连接，猎枪的枪管、机匣、枪托、扳机及杠杆连接合理；圣典有连续书脊、封皮与书页；晶刃轮廓清楚，武器不遮挡人物面部或标题。人物金色星形头部、双眼、手臂和披风结构正常。中文、英文标题无明显错字。
