# 0.3.1 兵器库选项分页

## 改动

- 主页面只保留“挑选兵器”“随心所欲”“百武皆通”三个选项。
- 保留轻巧、厚重、远程、特殊四组；进入“挑选兵器”后，在分类页选择。
- 分类和武器菜单共用分页：不超过3个内容项时，内容项加返回组成单页；超过3项时每页2个内容项，加翻页与返回，始终最多4项。
- 翻页按钮在尾页显示“回到第一页”；页面描述显示当前页与总页数。武器页“再想想”返回进入它时的分类页，分类页返回主页面。
- 导航按钮不写入选择历史、不确定武器、不消耗随机序列；实际武器选择与本局保存机制保持。
- 复用五张已验收插画。后续添加武器，只需将它加入所属组，菜单自动增加分页。
