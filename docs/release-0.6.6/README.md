## 与上次发布的差异

| 内容 | 0.6.4已发布 | 本次0.6.6 |
| --- | --- | --- |
| 武器数量 | 16件扩展主武器，加原版君王之剑 | 数量保持，共17件可淬炼兵器 |
| 图谱节点 | 淬炼一、淬炼二、淬玉，共3个 | 共9个：2主线、7支线 |
| 新支线 | — | 淬火、沉重、轻盈、断水、理气、怨魂，共6个新增节点；特化互斥后每把至多领取其中5项 |
| 升级 | 部分武器缺少或使用旧升级效果 | 指虎伤害+6、短匕斩杀金币+10，其余2／3费武器与圣棍基础费用−1 |
| 武器构筑 | 两阶专属淬炼与淬玉 | 额外支持费用／伤害特化、首次生成自动升级、多项附魔共存 |
| 图谱显示 | 已有原版字体、拖动缩放、HUD避让 | 中央竖直主线、周围独立支线、各任务颜色；修复详情导致右侧节点消失及英文按钮撑宽 |
| 文本 | 原有中英卡面、任务与提示 | 精简并校正任务／卡面／能力／附魔提示，补齐关键词颜色 |

任务完成条件在同一玩家的本局内计数，领奖与沉重／轻盈选择按武器分别记录；百武皆通不用为每把武器重新满足一次相同计数。生成类奖励只作用于领取后新铸造生成的主武器，不追补已存在的牌，不重复赋予已有牌，也不将小刀、子弹或充能当作主武器。

本次没有新增武器、改成永久跨局养成或实现海克斯大乱斗兼容。0.6.4已有的34项主线强化、淬玉、原版君王之剑开局选择、征服者及悬浮提示修复，不重复列为本次新增。
