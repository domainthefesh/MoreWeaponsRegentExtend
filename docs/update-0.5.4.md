# 0.5.4：铸造入口与单件武器悬浮预览

日期：2026-10-06。作者在 0.5.3 发布后反馈：已有模组武器时，原版征服者仍会生成君王之剑；同时要求铸造相关卡牌只预览本局所选武器。改动仅限本项目，没有新增依赖。

## 原因与逐项改动

1. **修复被内联的铸造入口。** 实际征服者仍调用 `ForgeCmd.Forge`。原补丁只拦截该异步方法的包装器；原版调用者先被优化 JIT 编译时，包装器会被内联，绕过 Harmony Prefix。原版 Forge 只识别 `SovereignBlade`，因此误认为没有武器并生成原版剑。真实征服者出牌夹具已复现这一时序，旧版 48 个组合全部发生错误，Prefix 命中为 0。
2. **保护统一 Forge 执行体。** 保留正常包装器补丁，增加 RitsuLib 的 `AsyncMethod` 目标，仅在 Forge 状态机初次执行时进入同一武器选择逻辑。原版各铸造卡、炉火／锤时能力、击剑手册及君王勇气药水使用同一入口；不逐张复制卡牌效果。已被包装器处理的调用不会进入此入口，异步续执行也不会再次铸造。
3. **保持等待与异常语义。** 安全网先初始化原 TaskBuilder 的 Task，再将统一铸造结果转发到同一 Task。征服者等待铸造完成后继续施加能力；铸造异常仍传回原调用者。反射仅发生在补丁安装时，运行时直接访问状态机字段。两个铸造入口补丁改为关键补丁，目标不兼容时报告失败。
4. **通用单件武器预览。** 原版卡牌 `HoverTips` 中的君王之剑预览统一替换为本局指定的主武器。招架不再添加全部 18 张武器。铸造、格挡、能力、关键词和其他附属卡提示仍保留。按卡牌所有者选择武器；无所有者的局内预览采用本地玩家，局外仍显示原版剑。
5. **随机玩法预览。** 随心所欲与百武皆通均显示原版君王之剑，不加载全部武器预览。新增按玩家保存的 `RandomlySelectedOnce` 标记，仅用于区分提示，不改变随机序列或实际生成武器。旧存档没有此标记时按原有固定武器状态读取：旧版随心所欲与手动选择原本保存为同一数据，无法可靠区分；重新开局选择后会记录正确模式。

此前 0.5.2 的征服者测试验证的是能力增伤，没有实际打出原版征服者，也没有覆盖先优化编译再安装补丁的时序。本轮新增真实 `CardCmd.AutoPlay`、`OnPlayWrapper` 与优化 JIT 复现，保留旧版失败记录；不将先前一般联动验收当作这一问题已经通过。

## 验证

本地编译 0 警告、0 错误；PCK 打包成功，279 项文件、74 项导入文件，资源 SHA256 与 0.5.3 相同。正式 ZIP 仅含 DLL、PCK、manifest，逐项 SHA256 与构建产物一致。

最终生产 DLL 的 **1,897 项断言通过**：

- 铸造专项两种时序各 678 项，共 **1,356 项**。真实原版征服者／升级征服者覆盖 16 武器 × 手牌／抽牌／弃牌堆，另验证首次生成、百武皆通、枪与子弹、晶刀、已消耗武器重生及原版剑共存。精炼之刃和 TheSmith 的真实出牌也通过。正常路径包装器命中 123 次，提前内联路径命中 0 次；两路 AfterForge 均恰好结算 123 次。真实挂起铸造后续流程、失败时异常传播均通过。
- 悬浮提示专项 **541 项**。真实 Ritsu PatchAll 与原生 CardModel.HoverTips，覆盖原版 14 张铸造／剑联动牌与趁手兵器 × 16 件固定武器，以及两种随机模式、多人卡牌所有者、无所有者和局外回退。每次恰好一张正确武器预览，非武器说明 ID 与顺序保持；预览可变数据不共享，晶刃附属小刀提示正常保留。
- 两套夹具确认实际加载 DLL 的 SHA256／MVID 与正式包相同，编译均 0 警告、0 错误。源码复审另核对实际 Forge 状态机初始状态、异常区域、TaskBuilder 共享及统一路由各分支。

证据与复现方法：[铸造专项](../.build/conqueror-0.5.4-validation/README.md)、[提示专项](../.build/hover-0.5.4-validation/README.md)、`.build/acceptance-0.5.4-build.log`、`.build/acceptance-0.5.4-zip-verify.log`。保留旧版真实失败的 `baseline-inline-failure.log`，最终两路固定日志为 `final-normal-verify.log` 和 `final-early-jit-verify.log`。

夹具采用最小战斗容器与 TestMode，执行真实原版卡牌、生产模型及 Ritsu 补丁；没有驱动实际游戏 UI、测量 FPS、真实保存写盘或验证所有第三方模组组合。单件提示减少预览数量，不据此宣称具体帧率提升。

## 游戏复验

1. 本局选定一把武器并铸造生成，再打出征服者／升级征服者：不应生成原版剑，现有武器正确增加 3／5 铸造，目标上的增伤仍生效。将武器放入抽牌／弃牌堆后重复。
2. 查看招架、征服者、精炼之刃、召唤之刃及其他铸造牌：只出现选定武器预览，其他提示正常。没有武器选择的局外卡库仍显示原版剑。
3. 新开随心所欲或百武皆通局：相关提示只出现原版剑，实际铸造继续遵循对应随机规则。
4. 皇室猎枪激活后铸造继续生成子弹，已有子弹正常增加铸造；战斗结束、读档与其他模组同时启用时留意是否出现新日志。
