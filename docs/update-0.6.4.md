# 0.6.4 皇家图谱显示修复

制作日期：2026-10-07。针对作者反馈的原版顶栏与遗物栏遮盖标题和关闭区，修正任务页布局。

## 改动

1. 任务页按原版顶栏背景与可见遗物槽的实际占用区域预留顶部安全区，不把遗物容器的空白高度算作占用。
2. 皇家图谱在剩余区域内等比缩放、居中，保留左右与底部余量；标题、关闭按钮、任务详情和领取按钮随整体布局移动。
3. 界面打开期间检测遗物换行、显示状态与窗口尺寸变化；占用范围改变才重新布局。安全区统一转换到任务页坐标，支持上层游戏UI缩放。
4. 保留原版HUD层级、皇家图谱的字体与节点、拖动缩放及任务规则；本轮没有修改武器或奖励效果。

## 验证

正式C#构建为0警告、0错误；资源包打包297项成功。使用实际生产DLL与PCK的原生HUD叠加夹具通过43项检查，Godot正常退出0，6张截图由主代理逐张查看。入口与玩法沿用0.6.3，本轮未重复未改动的战斗测试。

覆盖原版顶栏／遗物栏与任务页的同场景层级、多排遗物动态换行、遗物隐藏后释放空间、1280×720与800×450窗口、1600×1000留黑边、父UI缩放与偏移、小视口无强制最小缩放、详情／领取、Esc层级，以及通过原生GUI命中关闭按钮。遗物容器的空白外框未计作占用，主界面始终在剩余区域内。

同一夹具另加载旧0.6.3实际DLL与PCK，复现作者报告的标题和关闭区遮挡；旧版基线7项与截图单独保留，验证结束后已恢复正式0.6.4引用。

夹具保留原版`top_bar.tscn`背景资源、控件布局和`run.tscn`兄弟顺序，剥除依赖真实玩家的HUD脚本；遗物以原图标、合成60×60槽与实际HFlowContainer验证换行。HUD里的默认生命／金币／占位图标不是实际游戏状态；这项验证不等于完整客户端实机验收。证据及截图见[本轮界面审查](ui-0.6.4/README.md)。

受限执行环境第一次启动Godot时未能加载.NET程序集；放开仅验证进程的运行限制后正常加载，最终43项通过。夹具初次无HUD边界断言出现浮点误差，调整为1像素容差；补注册隔离场景缺少的原版输入动作后，最终日志没有相关输入错误。均未为此改动生产玩法或安装依赖。

## 游戏内验收

- 从顶栏入口打开任务页，检查“兵器淬炼”标题和右上关闭按钮完整可见；鼠标点击关闭按钮能返回游戏。
- 多排遗物与不同窗口尺寸下再次打开；任务页应完整处于HUD下方，底部不被裁切。
- 点开淬炼一、淬炼二和淬玉，检查详情与领取按钮；Esc先收起详情，再关闭任务页。
