# 0.6.3 皇家图谱与淬玉

制作日期：2026-10-07。基于已交付的0.6.2；作者选择方案A“皇家图谱”，将其接入正式原生任务界面。

## 改动

1. 右上角原有兵器淬炼入口打开新的皇家图谱。左侧保留17件兵器索引，图谱默认仅显示“淬炼一”“淬炼二”“淬玉”；任务要求、进度与奖励在点击节点后展示。
2. 字体使用游戏的本地化字体资源，配合彩色填充与深色描边。使用原版横栏和节点框资源；两项主线用直线连接，支线不与主线相连。图谱可拖动、缩放与归位；Esc先收起详情，再关闭整个界面。
3. 新增独立支线“淬玉”：本局赢得5场精英战斗后可以领取。按精英房间战斗胜利计数，不按房间内敌人数计数；重复胜利通知不会重复累计。
4. 领取淬玉后，对应兵器的基础攻击伤害增加4。固定武器与随机固定一把，仅能为该兵器领取；“百武皆通”允许各兵器分别领取。支线不要求先领取主线奖励。
5. 淬玉与铸造分开计算：轨迹炮不会把这4点放大为40点，短匕不会将其折半；圣棍仍按当前架势计算。子弹、水晶小刀沿用所属主武器的奖励归属；猎枪强化其炮击，君王之翼没有攻击伤害，不额外产生攻击。
6. 精英计数、去重位置与领取状态加入本局存档，兼容缺少新字段的旧载荷；新局重置。联网领取仍验证可信发送者、资格、完成条件和重复领取；右上角可领取数量包含支线。
7. 同步中英文任务与奖励文本，版本号升为0.6.3。没有安装第三方模组依赖，没有修改项目目录外文件。

## 游戏内验收

- 从地图附近的兵器淬炼入口打开任务页，确认三节点短名、主线直线、淬玉独立；点开节点才能看到任务条件。
- 赢得四场精英战斗时不可领取淬玉；第五场获胜后可领取，且不必先领取淬炼一或二。
- 领取后检查对应兵器卡面与实际攻击的4点基础增量，继续铸造、复制和重新生成卡牌，不应重复累加支线奖励。
- 保存退出后继续，确认精英计数与领取保留；新开局应归零。百武皆通逐件领取，固定玩法仅所选兵器可领取。
- 使用键盘／手柄切换兵器、节点与领取按钮，拖动、缩放及关闭任务页后，应能正常恢复游戏输入。

隔离验证不代替完整游戏客户端、真实保存退出或双客户端联机验收；海克斯大乱斗兼容仍按作者此前决定延期。
