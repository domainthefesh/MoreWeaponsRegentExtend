# 百般武艺：储君扩展

一个让储君不再只能铸造大剑的扩展模组。

本模组为储君新增了多种风格各异的“君王武器”，让每一次铸造都拥有更多变化与可能。

## 模组内容

本模组目前包含：

* 8 张“君王武器”
* 2 张附属衍生牌
* 多种截然不同的铸造效果
* 可自定义的武器铸造池

每次触发铸造时，默认会从模组提供的“君王武器”中随机选择一种进行铸造。

每件武器都拥有独特而强力的效果，能够为储君带来不同的战斗思路与构筑方向。

## 自定义铸造池

不喜欢完全随机？

你可以在模组设置中调整相关配置，自定义能够被铸造出的武器，并按照自己的喜好修改铸造池。

## 设计风格

本模组主要基于原版游戏的美术与机制风格进行设计，希望新增内容能够在保持原版体验的同时，为储君提供更加丰富、有趣的玩法。

如果你对新的武器、机制或卡牌效果有任何有趣的想法，欢迎留言分享！

## 前置依赖

本模组基于 **RitsuLib** 开发。

使用本模组前，请确保已经安装并启用对应版本的 RitsuLib 依赖库，否则模组可能无法正常加载。

## 安装方式

1. 订阅本模组。
2. 订阅并启用 RitsuLib。
3. 启动游戏并在模组列表中启用本模组。
4. 进入游戏后，即可体验新增的君王武器。
