# 百般武艺：储君扩展

一个让储君不再只能铸造大剑的扩展模组。

本模组为储君新增了多种风格各异的“君王武器”，让每一次铸造都拥有更多变化与可能。

## 模组内容

本模组目前包含：

* 16 件主武器
* 3 张附属衍生牌：水晶小刀、子弹、充能
* 1 张新增初始牌“趁手兵器”（替换储君的一张打击）
* 合计 20 张卡面
* 多种截然不同的铸造效果
* 涅奥事件后的开局兵器库选择
* 本局兵器淬炼：17件兵器各有两阶段首领奖励，以及独立精英支线“淬玉”

储君在涅奥事件结束后选择本局武器。指定武器或选择“随心所欲”后，本局需要生成武器时只会生成选定的武器；选择“百武皆通”则每次铸造重新随机。

每件武器都拥有独特而强力的效果，能够为储君带来不同的战斗思路与构筑方向。

## 出发前选兵器

从轻巧、厚重、远程、特殊四个分支中选择具体武器，也可以让兵器库随机选择一把并固定整局，或选择每次铸造都随机的“百武皆通”。

也可选择“选最熟悉的”，使用原版君王之剑。本局击败第一幕、第二幕首领后，在顶栏“兵器淬炼”界面领取对应兵器的专属强化。进度仅保存在本局存档，新开局重置；“百武皆通”允许各兵器分别领奖。

赢得5场精英战斗后，还可独立领取“淬玉”，使对应兵器基础攻击伤害增加4；无需先领取主线奖励。

选择按玩家保存在本局存档中，保存退出后仍保留。模组设置中的随机池开关已移除，旧配置不再决定铸造池。

## 设计风格

本模组主要基于原版游戏的美术与机制风格进行设计，希望新增内容能够在保持原版体验的同时，为储君提供更加丰富、有趣的玩法。

如果你对新的武器、机制或卡牌效果有任何有趣的想法，欢迎留言分享！
